Core Features

Everything you need for modern warehouse operations

Real-time Inventory

Track stock levels across multiple locations with instant updates and low-stock alerts.

Batch/Wave Picking

Group multiple orders into waves. Pick efficiently with location-grouped lists.

Packing Stations

Dedicated packing areas with tote assignment and scan validation.

Carrier Selection

Support for DHL, GLS, TDN, CORREOS with per-order carrier assignment.

ZPL Label Generation

Generate shipping labels in ZPL format with Code128 barcodes. Optional direct printing.

ERP-Ready API

RESTful API with Swagger documentation. Webhooks for real-time ERP sync.
