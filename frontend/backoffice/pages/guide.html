🚀 Quick Start Guide

Learn how to use the WMS end-to-end workflow

1

Create Products

Start by adding products to your warehouse inventory. Each product needs a SKU, name, and barcode for scanning.

Go to Products →
2

Create Orders

Create customer orders with product lines. Orders start in DRAFT status until you release them for picking.

Create Order →
3

Generate Pick Waves

Combine multiple orders into pick waves for efficient warehouse picking. The system groups items by location.

View Waves →
4

Pick Items

Pickers use Zebra handheld devices to scan locations and items. The system guides them through optimal paths.

Open Handheld →
5

Pack & Ship

At packing stations, operators scan totes, verify items, select carriers, and print shipping labels.

View Shipments →
